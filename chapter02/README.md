# Chapter 02

记忆-实现多轮交互

## 示例

```
You: 你好 
----------------------LOOP 1----------------------------------
[0]	USER:	 你好
[1]	ASSISTANT:	 你好！😊 很高兴见到你～有什么我可以帮助你的吗？
You: 你  我叫 sarto
----------------------LOOP 2----------------------------------
[0]	USER:	 你好
[1]	ASSISTANT:	 你好！😊 很高兴见到你～有什么我可以帮助你的吗？
[2]	USER:	 我叫 sarto
[3]	ASSISTANT:	 你好，Sarto！👋 很高兴认识你～

这个名字很有特色，是有什么特别的含义吗？😊 有什么我可以帮你的，尽管说！
You: 你知道我是谁吗
----------------------LOOP 3----------------------------------
[0]	USER:	 你好
[1]	ASSISTANT:	 你好！😊 很高兴见到你～有什么我可以帮助你的吗？
[2]	USER:	 我叫 sarto
[3]	ASSISTANT:	 你好，Sarto！👋 很高兴认识你～

这个名字很有特色，是有什么特别的含义吗？😊 有什么我可以帮你的，尽管说！
[4]	USER:	 你知道我是谁吗
[5]	ASSISTANT:	 嗯，目前我知道的是你叫 **Sarto**，这是你刚刚告诉我的 😊

除此之外，我对你的了解还不多。如果你愿意多分享一些关于自己的事情，我会很开心认识一个更完整的你！比如你的兴趣爱好、工作、或者任何你想聊的话题～
```

- 大模型服务端只会返回当前 message
- 客户端需要自行保留，决定展示给大模型服务端的 message 内容
- 有了 message 上下文，大模型类似拥有了记忆能力，但这种记忆本质上是上下文提供的
